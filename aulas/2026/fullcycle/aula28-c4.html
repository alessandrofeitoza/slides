O problema da documentação técnica

Muitas equipes documentam código demais...

...e arquitetura de menos.

O resultado é ninguém entender como o sistema funciona.

C4 Model

Uma forma simples de documentar arquitetura

Criado por Simon Brown

Por que o C4 surgiu?

Diagramas UML se tornaram complexos demais.

Muitas empresas deixaram de documentar arquitetura.

O C4 simplifica a comunicação arquitetural.

Os 4 níveis do C4

Context
Container
Component
Code

Nível 1 — Context Diagram

Mostra o sistema dentro do ambiente de negócio.

Quem usa?

Com quais sistemas ele conversa?

Exemplo: E-commerce


Cliente
   |
   v
E-commerce
   |
   +--> Gateway de Pagamento
   |
   +--> Correios
   |
   +--> ERP

Nível 2 — Container Diagram

Mostra os grandes blocos tecnológicos.

Não são Docker Containers.

São aplicações e bancos.

Exemplo: Netflix Simplificada


Frontend React
      |
      v
API Gateway
      |
      +--> Serviço de Filmes
      |
      +--> Serviço de Assinaturas
      |
      +--> Serviço de Recomendação

Banco PostgreSQL
Redis
Kafka

Nível 3 — Component Diagram

Mostra os módulos internos de uma aplicação.

Muito útil para DDD e Clean Architecture.

Exemplo: API Laravel


PedidoController
       |
PedidoService
       |
PedidoRepository
       |
PostgreSQL

Nível 4 — Code Diagram

Mostra classes e relacionamentos.

Muitas equipes nem chegam neste nível.

O código normalmente já é a documentação.
