01 — Antes do PHP: páginas estáticas

HTML enviado ao navegador
<h1>Olá, visitante!</h1>
<p>Hoje é dia 28 de outubro.</p>
O limite
  • HTML descreve conteúdo e estrutura.
  • Conteúdo personalizado precisa ser gerado ou alterado.
  • Contas, formulários e dados de banco exigem lógica além do HTML estático.
A web precisava de uma forma prática de gerar conteúdo dinamicamente no servidor.

02 — A história começa com uma necessidade

1994
PHP Tools

Rasmus Lerdorf cria scripts CGI em C para acompanhar visitas ao seu currículo online.

1995
Código aberto

As ferramentas são disponibilizadas publicamente e ganham recursos e usuários.

1997–98
PHP/FI → PHP 3

Rasmus, Andi Gutmans e Zeev Suraski colaboram na reescrita que dá forma ao PHP moderno.

2000
PHP 4

O Zend Engine melhora desempenho e estrutura o núcleo da linguagem.

2004
PHP 5

O Zend Engine 2 traz um modelo de objetos mais robusto.

2015
PHP 7

Grande evolução de desempenho e uso de memória, com o Zend Engine 3.

2020
PHP 8

Tipos de união, atributos, argumentos nomeados, match, operador nullsafe e JIT.

Hoje
PHP moderno

Tipagem mais expressiva, ferramentas maduras e versões evoluindo continuamente.

A ideia central
Resolver problemas reais

De ferramentas pessoais a uma linguagem para aplicações web de diferentes portes.

03 — O nome PHP mudou de significado

Origem

Personal Home Page Tools

Um conjunto de ferramentas para páginas pessoais.

Significado atual

PHP: Hypertext Preprocessor

Um acrônimo recursivo: o próprio PHP aparece na expansão do nome.

  • PHP não nasceu como uma linguagem inteiramente planejada desde o primeiro dia.
  • Cresceu conforme desenvolvedores precisavam resolver problemas concretos da web.
  • A história ajuda a entender a integração da linguagem com HTML.

04 — PHP não é JavaScript

PHP · servidor
<?php
$nome = 'Ana';
echo "Olá, {$nome}!";
  • Executa no servidor.
  • Pode consultar banco e aplicar regras de negócio.
  • O resultado pode ser HTML ou JSON.
JavaScript · navegador
const nome = 'Ana';

document.querySelector('h1')
  .textContent = `Olá, ${nome}!`;
  • Controla a interface e reage às ações.
  • Também pode executar no servidor com Node.js.
A diferença principal não é “um é melhor”: é onde o código executa e qual responsabilidade assume.

05 — Como uma página PHP chega ao navegador?

Navegador→Servidor web→PHP
PHP processa→HTML resultante→Navegador
Arquivo no servidor
<h1>
  Olá, <?= htmlspecialchars($nome) ?>!
</h1>
Resposta enviada
<h1>
  Olá, Ana!
</h1>
  • O navegador recebe a resposta gerada, não o código PHP original.
  • PHP pode misturar lógica e HTML; projetos maiores se beneficiam de separar responsabilidades.

06 — Seu primeiro script

hello.php
<?php

echo 'Olá, mundo!';
O que significa?
  • <?php inicia o código PHP.
  • echo escreve conteúdo na saída.
  • O ponto e vírgula encerra a instrução.
  • Em arquivos PHP puros, normalmente omitimos a tag de fechamento.
O arquivo precisa ser executado pelo PHP. Abrir um .php diretamente como arquivo local não substitui um servidor PHP.

07 — Variáveis e tipos

PHP
$nome = 'Chiquim';
$idade = 42;
$ativo = true;
$saldo = 125.50;

echo $nome;
echo $idade;
Pontos importantes
  • Variáveis começam com $.
  • Nomes diferenciam maiúsculas de minúsculas.
  • O tipo é inferido a partir do valor atribuído.
  • Strings, inteiros, floats, booleanos, arrays e objetos são tipos comuns.

Use nomes claros e valores que representem o problema.

08 — Condições e repetição

Decisão
$nota = 8;

if ($nota >= 7) {
    echo 'Aprovado';
} else {
    echo 'Precisa recuperar';
}
Repetição
$nomes = ['Ana', 'João', 'Ravi'];

foreach ($nomes as $nome) {
    echo $nome . '<br>';
}
  • As estruturas lembram as que você já viu em JavaScript.
  • foreach é muito usado para percorrer arrays e coleções.
  • O operador . concatena strings em PHP.

09 — PHP pode gerar HTML dinamicamente

PHP + HTML
<?php
$produtos = [
    ['nome' => 'Caderno', 'preco' => 15],
    ['nome' => 'Caneta', 'preco' => 3],
];
?>
<ul>
  <?php foreach ($produtos as $produto): ?>
    <li>
      <?= htmlspecialchars($produto['nome']) ?>:
      R$ <?= number_format($produto['preco'], 2, ',', '.') ?>
    </li>
  <?php endforeach; ?>
</ul>
Resultado esperado
  • Caderno: R$ 15,00
  • Caneta: R$ 3,00

Array de dados → HTML gerado no servidor

  • PHP decide quais elementos HTML serão enviados.
  • htmlspecialchars() ajuda a exibir texto com segurança no HTML.

10 — Onde o PHP entra numa aplicação?

Requisição HTTP→Rota / controlador→Regra de negócio
Banco de dados↔PHP→HTML ou JSON
PHP pode cuidar de
  • Validar dados recebidos.
  • Aplicar regras de negócio.
  • Consultar ou atualizar banco de dados.
  • Controlar autenticação e autorização.
  • Gerar páginas ou respostas de API.
Mas PHP não é...
  • Um banco de dados.
  • Um servidor web por si só.
  • Um framework específico.
  • Uma garantia automática de segurança ou boa arquitetura.

PHP

Sintaxe, tipos, funções, classes, arrays, exceções e recursos da linguagem.

Boas práticas desde o começo

Pequenas escolhas que evitam problemas

  • Use nomes de variáveis claros e consistentes.
  • Valide os dados recebidos; nunca confie cegamente na entrada do usuário.
  • Escape dados de acordo com o contexto de saída, como HTML.
  • Separe acesso a dados, regras de negócio e apresentação quando necessário.
  • Use versões suportadas do PHP e consulte a documentação oficial.

Desafio final — Catálogo de produtos

Requisitos
  • Crie um arquivo PHP com uma lista de produtos com nome e preço.
  • Use foreach para gerar uma lista HTML.
  • Formate os preços para reais.
  • Mostre uma mensagem diferente se a lista estiver vazia.
  • Destaque produtos com preço acima de R$ 50.
