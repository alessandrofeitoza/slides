Tema 1 · PHP: fundamentos

Questão 1 — Sintaxe PHP

Dos códigos PHP apresentados, assinale aquele que apresenta estrutura sintática correta e que possa ser processado sem problema.

  • A) <?php echo "Ola,Mundo!".?>
  • B) <?php echo "Ola,Mundo!";>
  • C) <?php echo Ola,Mundo!; ?>
  • D) <?php echo "Ola,Mundo!";?>
  • E) <?php echo "Ola,Mundo!; ?>

Resposta correta: D

Explicação · Questão 1

Uma instrução PHP válida

O bloco PHP começa com <?php e termina com ?>.

A instrução echo recebe uma string delimitada por aspas e termina com ponto e vírgula.

<?php echo "Ola,Mundo!"; ?>
Atenção aos três elementos: abertura do PHP, string corretamente delimitada e encerramento da instrução.
Tema 1 · PHP: fundamentos

Questão 2 — Variáveis

Para se declarar uma variável em PHP, é necessário iniciar seu nome de que forma?

  • A) Com o caractere $.
  • B) Com o caractere @.
  • C) Com o caractere #.
  • D) Com o caractere %.
  • E) Com o caractere !.

Resposta correta: A

Explicação · Questão 2

O cifrão identifica variáveis

Em PHP, toda variável começa com $, seguido pelo nome.

$nome = "Ana"; $idade = 25; $ativo = true;

O cifrão faz parte da sintaxe da variável. Ele não é usado para declarar constantes.

Tema 1 · PHP: fundamentos

Questão 3 — Precedência de operadores

Considere o código abaixo. Por que a variável $c recebe valor verdadeiro, mesmo com $b = false?

$a = true; $b = false; $c = $a and $b; echo $c ? "verdadeiro" : "falso";
  • A) Um bug na versão do PHP.
  • B) A precedência dos operadores faz a atribuição ocorrer antes da operação lógica and.
  • C) O operador ternário inverte o valor lógico.
  • D) O echo imprime sempre a primeira string.
  • E) A avaliação de curto-circuito ignora todos os operandos.

Resposta correta: B

Explicação · Questão 3

and tem baixa precedência

Em PHP, and tem precedência menor que o operador de atribuição. A expressão é interpretada como:

($c = $a) and $b;

Primeiro, $c recebe true. Depois, o resultado da expressão lógica é calculado, mas não é atribuído novamente a $c.

Para atribuir o resultado lógico, use parênteses ou o operador &&: $c = ($a and $b);

Questão 4 — Comparação de valores

Analise o código. Qual mensagem será apresentada?

$x = 10; if ($x == '10') { echo "SIM"; } else { echo "NÃO"; }
  • A) "SIM", pois o operador == compara apenas o valor, sem exigir o mesmo tipo.
  • B) "SIM", pois == é um operador de atribuição.
  • C) "NÃO", pois valores de tipos diferentes não podem ser comparados.
  • D) "NÃO", pois strings devem usar aspas duplas.
  • E) "NÃO", pois comparar tipos diferentes sempre retorna falso.

Resposta correta: A

Explicação · Questão 4

== versus ===

O operador == compara os valores com conversão de tipos quando aplicável. Por isso, nesse exemplo, o resultado é SIM.

10 == '10' // true 10 === '10' // false

Já o operador === compara valor e tipo.

Em código PHP, prefira comparação estrita quando a intenção for evitar conversões implícitas.
Tema 2 · Formulários e HTTP

Questão 5 — GET e POST

Ao desenvolver formulários HTML integrados a PHP, qual alternativa descreve corretamente os métodos GET e POST?

  • A) GET envia dados na URL, por query strings; POST envia os dados no corpo da requisição.
  • B) $_POST deve ser usado exclusivamente com method="get".
  • C) $_REQUEST captura apenas dados enviados por POST.
  • D) POST expõe os pares chave-valor na URL.
  • E) GET é o único método HTTP capaz de acionar scripts PHP por formulários.

Resposta correta: A

Explicação · Questão 5

Onde os dados são enviados?

GET: os parâmetros são enviados na URL, após o caractere ?.

POST: os dados são enviados no corpo da requisição HTTP.

<form action="processar.php" method="post"> <input name="nome"> </form> // processar.php $nome = $_POST["nome"];
POST não significa criptografia. Para proteger dados em trânsito, é necessário utilizar HTTPS.
Tema 2 · Formulários e HTTP

Questão 6 — Variáveis superglobais

Quais identificadores são variáveis superglobais do PHP usadas para acessar dados enviados por formulários?

  • A) $_FORM, $_HTTP
  • B) $_GET, $_POST
  • C) $_SUPER_GET, $_SUPER_POST
  • D) $_FORM, $_RESPONSE
  • E) $_SUPER_FORM, $_SUPER_HTTP

Resposta correta: B

Explicação · Questão 6

Superglobais disponíveis no PHP

  • $_GET: parâmetros recebidos pela URL.
  • $_POST: dados recebidos no corpo de uma requisição POST.
  • $_SERVER: informações do servidor e do ambiente de execução.

São arrays associativos disponibilizados pelo PHP e acessíveis em diferentes escopos.

Tema 2 · Formulários e HTTP

Questão 7 — Variáveis e superglobais

Analise as afirmativas sobre variáveis e superglobais em PHP:

I. O nome de uma variável deve começar com $.

II. $_GET armazena dados enviados no corpo de uma requisição POST.

III. $_SERVER contém informações do servidor, cabeçalhos e ambiente de execução.

É verdadeira(s) apenas a(s) afirmativa(s):

  • A) I.
  • B) II.
  • C) I e III.
  • D) II e III.
  • E) I, II e III.

Resposta correta: C

Explicação · Questão 7

Identifique a origem de cada dado

I — Verdadeira: variáveis PHP começam com $.

II — Falsa: $_GET recebe parâmetros da URL. Dados de POST ficam em $_POST.

III — Verdadeira: $_SERVER reúne informações sobre servidor, requisição e ambiente.

Atenção: $_GET e $_POST indicam a origem dos dados, não o tipo de dado armazenado.
Tema 3 · PHP: arrays

Questão 8 — Array indexado

Considere o array abaixo. Qual instrução apresenta o conteúdo do primeiro elemento?

$estados = array("AM", "AP", "DF", "PR", "SP", "SC", "RS");
  • A) echo $estados[1];
  • B) print($estados[1]);
  • C) print_r($estados[1]);
  • D) print($estados);
  • E) echo $estados[0];

Resposta correta: E

Explicação · Questão 8

O índice começa em zero

Em arrays indexados numericamente, o primeiro elemento ocupa a posição 0.

$estados[0] // "AM" $estados[1] // "AP"

echo e print exibem valores. print_r é útil para visualizar estruturas, como arrays.

Tema 3 · PHP: arrays

Questão 9 — Array associativo

Qual alternativa descreve corretamente a manipulação de arrays associativos em PHP?

  • A) As chaves podem ser inteiros ou strings, permitindo associar identificadores como "id", "nome" e "email" aos valores.
  • B) As chaves textuais precisam estar em ordem alfabética.
  • C) É proibido percorrer arrays associativos com foreach.
  • D) PHP não permite desestruturar arrays associativos.
  • E) Arrays associativos perdem suas chaves ao serem passados para funções.

Resposta correta: A

Explicação · Questão 9

Chaves nomeadas facilitam a leitura

$usuario = [ "id" => 10, "nome" => "Ana", "email" => "ana@example.com" ]; echo $usuario["nome"]; foreach ($usuario as $chave => $valor) { // percorre chave e valor }

Arrays associativos relacionam uma chave a um valor. As chaves podem ser inteiros ou strings.

Tema 4 · PHP e banco de dados

Questão 10 — PHP no servidor

Sobre o funcionamento e o processamento de páginas dinâmicas escritas em PHP, assinale a alternativa correta.

  • A) As páginas PHP são processadas integralmente no navegador.
  • B) O PHP é executado no servidor, gera um resultado — como HTML — e o envia ao navegador.
  • C) É proibido misturar HTML e PHP no mesmo arquivo.
  • D) PHP é uma linguagem exclusiva do lado cliente.
  • E) O código PHP não pode interagir com bancos de dados.

Resposta correta: B

Explicação · Questão 10

PHP é executado no lado servidor

O navegador faz uma requisição. O servidor executa o PHP e devolve uma resposta HTTP, que pode conter HTML.

Navegador ↓ requisição HTTP Servidor executa PHP ↓ resposta HTML Navegador renderiza a página
O usuário recebe a saída produzida pelo PHP, não o código-fonte PHP executado no servidor.
Tema 4 · PHP e banco de dados

Questão 11 — Integração com banco de dados

Uma aplicação PHP precisa cadastrar e consultar clientes armazenados em um banco de dados. Qual alternativa está correta?

  • A) PHP pode conectar-se ao banco, executar SQL e usar os resultados para gerar conteúdo dinâmico.
  • B) PHP não possui recursos para trabalhar com bancos de dados.
  • C) O banco precisa ser instalado no navegador do usuário.
  • D) PHP substitui completamente a linguagem SQL.
  • E) A conexão permite apenas consultar dados, não inserir, alterar ou excluir.

Resposta correta: A

Explicação · Questão 11

PHP conecta a aplicação aos dados

O PHP pode estabelecer conexão com bancos relacionais, executar comandos SQL e tratar os resultados.

  • INSERT: cadastrar registros.
  • SELECT: consultar registros.
  • UPDATE: atualizar registros.
  • DELETE: excluir registros.
PHP e SQL têm responsabilidades diferentes: PHP implementa a lógica da aplicação; SQL consulta e manipula os dados no banco.
Tema 5 · SQL

Questão 12 — Consultar dados

Qual comando SQL é usado para selecionar dados de uma tabela?

  • A) INSERT
  • B) UPDATE
  • C) DELETE
  • D) SELECT
  • E) CREATE

Resposta correta: D

Explicação · Questão 12

SELECT recupera informações

O comando SELECT consulta dados em uma ou mais tabelas.

SELECT * FROM Usuarios; SELECT nome FROM Usuarios WHERE id = 1;

O asterisco representa todas as colunas. A cláusula WHERE restringe os registros retornados.

Tema 5 · SQL

Questão 13 — Inserir dados

Qual comando SQL insere um novo registro na tabela Usuarios?

  • A) UPDATE Usuarios SET nome = 'João';
  • B) INSERT INTO Usuarios (nome) VALUES ('João');
  • C) SELECT * FROM Usuarios;
  • D) DELETE FROM Usuarios WHERE id = 1;
  • E) CREATE TABLE Usuarios (nome VARCHAR(50));

Resposta correta: B

Explicação · Questão 13

INSERT INTO cria registros

A estrutura básica informa a tabela, as colunas e os valores que serão inseridos.

INSERT INTO Usuarios (nome) VALUES ('João');

Não confunda:

  • INSERT: insere registros.
  • UPDATE: altera registros existentes.
  • DELETE: remove registros.
  • CREATE TABLE: cria uma tabela.

A respeito da definição e das características do Document Object Model (DOM), assinale a opção correta.

  • A) É uma extensão proprietária exclusiva do JavaScript.
  • B) É uma representação estruturada em árvore, composta por nós e objetos com propriedades, métodos e eventos.

JavaScript pode acessar e modificar essa estrutura, seus atributos, conteúdos e eventos.

Tema 6 · HTML e CSS

Questão 19 — CSS externo

Um site possui 20 páginas. A responsável deseja alterar um único arquivo para atualizar a aparência de todas elas. Qual é a forma mais adequada?

  • A) Usar CSS inline em cada elemento.
  • B) Usar CSS interno em cada página.
  • C) Alterar manualmente o HTML de cada página.
  • D) Usar CSS externo, criando um arquivo .css ligado a todas as páginas.
  • E) Usar CSS inline apenas no elemento body de cada página.

Resposta correta: D

Explicação · Questão 19

Centralize os estilos compartilhados

Um arquivo CSS externo pode ser compartilhado por várias páginas HTML.

<link rel="stylesheet" href="estilos.css">

Ao alterar estilos.css, todas as páginas que carregam esse arquivo podem refletir a mudança.

Inline: no próprio elemento. Interno: na página, dentro de <style>. Externo: em arquivo separado.

Tema 7 · JavaScript e DOM

Questão 21 — Tipagem dinâmica

JavaScript é categorizada como uma linguagem fracamente tipada. O que essa característica implica na declaração e no uso de variáveis?

  • A) A linguagem proíbe números fracionários em variáveis já declaradas.
  • B) É obrigatório declarar explicitamente o tipo primitivo antes de atribuir um valor.
  • C) As variáveis não exigem definição explícita do tipo e podem receber tipos distintos dinamicamente.
  • D) Todas as variáveis declaradas com var são convertidas em texto.
  • E) As variáveis tornam-se constantes após a primeira atribuição.

Resposta correta: C

Explicação · Questão 21

O tipo está associado ao valor

JavaScript permite atribuir valores de tipos diferentes à mesma variável ao longo da execução.

let dado = 10; dado = "dez"; dado = true;

Não é necessário declarar previamente um tipo como int ou string.

A questão usa a expressão “fracamente tipada”; o ponto central cobrado é a tipagem dinâmica e a ausência de declaração explícita de tipo.
Tema 7 · JavaScript e DOM

Questão 22 — Método filter()

Um array contém preços de produtos. É necessário gerar um novo array apenas com valores superiores a 150. Qual método nativo deve ser utilizado de forma declarativa?

const precos = [100, 200, 300, 400];
  • A) forEach(), que modifica diretamente o array original.
  • B) map(), transformando cada elemento com uma condição.
  • C) filter(), que retorna um novo array com os elementos que atendem à condição.
  • D) reduce(), acumulando os dados em uma variável numérica.
  • E) pop(), removendo elementos do final da estrutura.

Resposta correta: C

Explicação · Questão 22

filter() seleciona elementos

O método percorre o array e retorna um novo array com os elementos para os quais a função de teste retorna verdadeiro.

const precos = [100, 200, 300, 400]; const selecionados = precos.filter( preco => preco > 150 ); // [200, 300, 400]

O array original não é alterado por filter().
