01 — HTML é estrutura, JS é comportamento

HTML · estrutura
<h1 id="titulo">Olá!</h1>
<button id="botao">
  Clique aqui
</button>
<script src="app.js" defer>
</script>
JavaScript · comportamento
const botao = document
  .querySelector('#botao');

botao.addEventListener('click', () => {
  document.querySelector('#titulo')
    .textContent = 'Você clicou!';
});
  • HTML descreve o conteúdo e a estrutura.
  • JavaScript encontra elementos e reage às ações da pessoa.
  • defer faz o script externo executar após o HTML ser analisado.

02 — O que é o DOM?

HTML escrito
<main>
  <h1>Minha página</h1>
  <p>Aprendendo JavaScript</p>
</main>
Árvore simplificada
document
└── html
    └── body
        └── main
            ├── h1
            │   └── "Minha página"
            └── p
                └── "Aprendendo JavaScript"
  • DOM significa Document Object Model.
  • O navegador representa o documento como objetos organizados em uma árvore.
  • O JavaScript pode consultar e modificar essa representação.

Pode ser HTML ou XML (são as tags em si)

03 — Encontrando elementos

HTML
<p id="mensagem">Texto inicial</p>
<p class="aviso">Atenção</p>
<p class="aviso">Importante</p>
JavaScript
const mensagem = document
  .querySelector('#mensagem');

const mensagem = document
  .getElementById('mensagem');

const aviso = document
  .querySelector('.aviso');

const avisos = document
  .querySelectorAll('.aviso');

console.log(avisos.length); // 2
  • #id seleciona pelo identificador; .classe seleciona pela classe.
  • querySelector retorna o primeiro elemento correspondente ou null.
  • querySelectorAll retorna uma lista estática dos elementos correspondentes.

04 — Lendo e alterando conteúdo

Código
const titulo = document
  .querySelector('#titulo');

console.log(titulo.textContent);
titulo.textContent = 'Novo título';

titulo.classList.add('destaque');
titulo.classList.toggle('oculto');

Título original

Este conteúdo pode mudar.

  • textContent lê ou altera texto sem interpretar HTML.
  • classList.add/remove/toggle controlam classes CSS.
  • Para texto vindo do usuário, prefira textContent a innerHTML.

05 — Eventos: reagindo ao usuário

JavaScript
const botao = document
  .querySelector('#contar');
const saida = document
  .querySelector('#contador');
let total = 0;

botao.addEventListener('click', () => {
  total++;
  saida.textContent = total;
});
Experimente no slide

Cliques: 0

  • Um evento representa algo que aconteceu: clique, digitação, envio de formulário.
  • addEventListener registra uma função para executar quando o evento ocorrer.
  • Evite misturar comportamento JavaScript diretamente em atributos como onclick.

06 — Formulários e preventDefault()

JavaScript
const form = document
  .querySelector('#form-nome');
const campo = document
  .querySelector('#nome');
const resultado = document
  .querySelector('#resultado');

form.addEventListener('submit', event => {
  event.preventDefault();
  resultado.textContent =
    `Olá, ${campo.value}!`;
});
Experimente no slide

  • submit é o evento de envio do formulário.
  • event.preventDefault() impede o comportamento padrão, como recarregar a página.
  • input.value acessa o valor digitado em um campo.

07 — Criando elementos dinamicamente

JavaScript
const lista = document
  .querySelector('#lista');
const item = document.createElement('li');

item.textContent = 'Estudar DOM';
lista.append(item);

// Para remover um elemento:
item.remove();
Experimente no slide
  • Aprender HTML

Clique em uma tarefa para removê-la.

  • createElement cria um elemento; append o adiciona ao documento.
  • remove remove o próprio elemento.
  • Combine eventos, funções e DOM para criar interfaces pequenas e úteis.

08 — Arrays de objetos viram interface

Dados + renderização
const produtos = [
  { nome: 'Caderno', preco: 15 },
  { nome: 'Caneta', preco: 3 },
  { nome: 'Mochila', preco: 80 }
];

produtos.forEach(produto => {
  const item = document.createElement('li');
  item.textContent =
    `${produto.nome}: R$ ${produto.preco}`;
  lista.append(item);
});
O que aparece na página
  • Caderno: R$ 15
  • Caneta: R$ 3
  • Mochila: R$ 80

Dados estruturados → elementos HTML

  • APIs frequentemente retornam arrays de objetos.
  • O DOM permite transformar cada objeto em conteúdo visível.
  • Na próxima etapa, esses dados poderão vir de uma API real.

Boas práticas

Pequenas escolhas que evitam problemas

  • Use seletores claros e nomes de variáveis descritivos.
  • Use defer ou carregue o script após o HTML.
  • Verifique se um elemento existe antes de usá-lo quando necessário.
  • Prefira textContent para inserir texto não confiável.
  • Separe HTML, CSS e JavaScript em arquivos próprios.

Desafio final — Lista de tarefas

Requisitos
  • Um campo de texto, um radio de prioridade (alta, baixa, ou media), um select de categoria (estudo, trabalho, lazer, etc) e um botão para adicionar tarefas.
  • Adicionar tarefas à lista sem recarregar a página.
  • Não permitir tarefas vazias.
  • Não permitir tarefas duplicadas (mesmo titulo, prioridade e categoria)
  • Clicar em uma tarefa para marcá-la como concluída.
  • Gravar data e horário que a tarefa for concluida
  • Marcar tarefas como concluidas com um estilo visual diferente
  • Adicionar um botão para remover cada tarefa.
