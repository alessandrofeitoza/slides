Resposta correta

Separar os valores informados pelo usuário da estrutura do comando SQL, reduzindo o risco de SQL Injection.

Questão 20 de 20Prova 0124748 · Questão 10

Por que a C?

  • O SQL é enviado com marcadores (? ou :nome); os valores vão separados.
  • Assim, o que o usuário digita é tratado sempre como dado, nunca como comando SQL.
  • A B exagera: reduz o risco de injeção, mas não substitui permissões e controle de acesso.
// perigoso: valor colado no SQL
$pdo->query("INSERT INTO usuarios (nome) VALUES ('$nome')");

// seguro: prepared statement
$stmt = $pdo->prepare("INSERT INTO usuarios (nome, email) VALUES (?, ?)");
$stmt->execute([$nome, $email]);
